# 슬립메이트 — 친구와 함께 일찍 잠드는 앱 프로토타입

빌드 없이 바로 열리는 정적 사이트입니다. `index.html` 하나에 휴대폰 한 대가 떠 있고, 실제 앱처럼 한 흐름으로 이어집니다.

1. **홈 화면**에서 슬립메이트 알림(또는 앱 아이콘·위젯)을 누릅니다.
2. **슬립메이트**에서 태엽을 돌려 오늘 밤 폰 사용 시간을 정하고 `이대로 감기 완료`를 누릅니다. 이때부터 시간이 흐릅니다(실제 1초 = 앱 속 1분).
3. 홈으로 돌아가(화면 아래 바 또는 `홈으로`) **모먼트** 앱을 엽니다.
4. 피드 위에 **팝업 시계**가 떠서 남은 시간·친구 불빛·투명도가 시간에 따라 바뀌고, 친구가 잠들거나 목표 시각이 되면 소등 알림이 올라옵니다.
5. `나도 끄고 자기` → `잘 자요` 화면에서 수면 측정을 켜고 `아침으로 넘어가기`를 누르면 다음 날 아침 요약이 나오고, `오늘 밤 23:00으로`로 다음 밤을 이어서 체험할 수 있습니다.

## v2 개선 기능 체험 포인트

| 기능 | 어디서 보나 |
| --- | --- |
| I-01 자동 반복 · I-02 평일/주말 | 첫 `이대로 감기 완료` 뒤 묻는 시트, **시계** 탭 아래 ‘매일 반복’ 설정(시간 −/+, 평일·주말 시간, 주말 요일 선택). 다음 밤에는 자동으로 감겨 있음 |
| I-03 연장 횟수·미션 · I-04 재알림 | 목표 시각 알림의 `5분만 더 (3/3)`. 4번째부터 연장 미션(ASMR·글 읽기·광고·강의) |
| I-05 연장 그래프 | **기록** 탭 결과 카드의 ‘연장 N번’, 주간 막대 위 점, `연장 횟수` 보기(주/월 누적 비교) |
| I-06 상태별 불빛 · I-07 먼저 잠든 친구 | 팝업·**메이트 › 수면 그룹**·위젯의 노랑/빨강(깜빡임)/회색, 잠든 순서대로 밝기가 다른 달 |
| I-08 잠들기 제안 | 목표를 넘긴 친구가 있을 때 `나도 끄고 자기` → 영상 골라 보내기. 내가 목표를 넘긴 채 깨어 있으면 친구가 보내 옴 |
| I-10 1:1 대결 | **메이트 › 1:1 대결**. ‘예시 결과로 채우기’로 끝까지 볼 수 있고, 끝난 대결은 ‘지난 대결’에 쌓임 |
| I-11 내 불빛 | **내 정보 › 내 불빛**. 고른 모양은 브라우저에 저장돼 새로고침해도 유지(‘처음부터 다시 보기’를 누르면 초기화) |
| I-12 수면 측정·스마트 알람 | `잘 자요` 화면의 측정 동의 → 아침 알람 → **기록** 탭 ‘날짜별 수면 단계’(캘린더로 날짜 선택) |

슬립메이트 앱 메뉴: **시계 · 메이트(수면 그룹 / 1:1 대결) · 기록 · 내 정보**. 내 정보의 프로필·계정·알림 등 일반 항목은 화면만 구성돼 있습니다.
